# MathLOG

A math workspace in the browser: notes, diagrams, calendars, and KaTeX — closer to a personal math OS than a calculator.

**Stack:** Next.js · TypeScript · Tailwind · Supabase · TipTap · React Flow · Recharts · FullCalendar · KaTeX

## Features

- Structured notes with typography + KaTeX
- Node graphs (React Flow) for proofs / concept maps
- Calendar view for practice blocks
- Tables and charts for problem sets
- Supabase-backed data when configured

## Local run

```bash
git clone https://github.com/mananbharti/MathLOG.git
cd MathLOG
npm install
npm run dev
```

See `DEPLOYMENT.md` for Netlify / Railway / Docker notes.
